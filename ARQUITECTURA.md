## ?? Principios SOLID Aplicados

### Single Responsibility Principle (SRP)
- Cada capa tiene una responsabilidad específica
- Separación clara entre Controllers, Services y Repositories

### Open/Closed Principle (OCP)
- Uso de interfaces para extensibilidad
- Nuevas entidades pueden agregarse sin modificar código existente

### Liskov Substitution Principle (LSP)
- Repository genérico implementado con BaseEntity
- Servicios trabajan con abstracciones

### Interface Segregation Principle (ISP)
- Interfaces específicas (ICompanyService, IRepository)
- No se fuerza a implementar métodos innecesarios

### Dependency Inversion Principle (DIP)
- Las capas superiores dependen de abstracciones
- Inyección de dependencias configurada en Program.cs
